Methodology

The Project Journey

A complete structural breakdown of how we progressed from problem identification to deploying a fully functional machine learning model.

PHASE 01 : INITIATION

Problem Identification

Traditional library systems act as passive record-keepers. We identified key inefficiencies:

  • Inability to forecast stock shortages during peak demand.
  • Lack of departmental usage metrics.
  • Manual, error-prone overdue fine calculations.
PHASE 02 : DATA COLLECTION

Synthetic Dataset Engineering

To avoid PII privacy issues with real student data, Aman and Trigya engineered a robust synthetic dataset using Python.

  • 1,000+ distinct transaction records.
  • Mapped against 200 virtual students and 30 books.
  • Introduced edge cases (nulls) to test cleaning pipelines.
PHASE 03 : PREPROCESSING

Data Cleaning & EDA

Executed in Jupyter Notebooks using Pandas and NumPy. We transformed raw data into model-ready numerical formats.

  • Imputed missing `ReturnDate` values logically.
  • Engineered the crucial `Days_Overdue` feature.
  • Generated 8 statistical charts using Matplotlib & Seaborn.
PHASE 04 : MACHINE LEARNING

Linear Regression Model

Developed supervised learning algorithms using Scikit-Learn to establish mathematical rules for administrative tasks.

  • Input: Extracted `Days_Overdue`.
  • Output: Predicted `Fine_Amount`.
  • Eliminates manual calculation errors entirely.
PHASE 05 : DEPLOYMENT

Documentation & Web Interface

Compiled the pipeline into a presentable format for academic evaluation (Session 2025-26).

  • Kartik & Tanishka finalized PPTs and IEEE reports.
  • Farhan developed this responsive front-end UI.
  • Deployed codebase via GitHub Pages.

Predictive Engine

Automated Fine Prediction via Linear Regression

To eliminate manual, error-prone calculations by library staff, we deployed a Supervised Machine Learning algorithm using `scikit-learn`.

The model digests engineered features—specifically `Days_Overdue`—to output exact financial liability instantly. Because the relationship between time and penalties is continuous, Linear Regression provided optimal reliability.

from sklearn.model_selection import train_test_split from sklearn.linear_model import LinearRegression # Define Independent (X) and Dependent (y) variables X = df[['Days_Overdue']] y = df['Fine_Amount'] # 80/20 Train-Test Split X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2) # Initialize and Train Model model = LinearRegression() model.fit(X_train, y_train)
